# Kronos Service

This service is a thin HTTP wrapper around the upstream `shiyu-coder/Kronos`
predictor. It lets the main FastAPI app call Kronos without importing PyTorch
or model-loading dependencies into the application process.

## Contract

The main API calls:

```text
POST /forecast
```

Request fields:

- `ticker`, `exchange`
- `bars`: historical OHLCV rows with `amount` zero-filled when unavailable
- `future_times`: trading-day timestamps generated by the main app calendar
- `pred_len`, `sample_count`, `temperature`, `top_p`

Response:

```json
{
  "ticker": "AAPL",
  "exchange": "NASDAQ",
  "forecast_path": [
    {
      "time": "2026-06-08",
      "open": 101.0,
      "high": 102.0,
      "low": 100.0,
      "close": 101.5,
      "volume": 1000000.0,
      "amount": 0.0
    }
  ]
}
```

## Local Setup

Use a separate Python environment for this service when installing Kronos model
dependencies.

```powershell
git clone https://github.com/shiyu-coder/Kronos vendor/Kronos
git -C vendor/Kronos checkout 67b630e67f6a18c9e9be918d9b4337c960db1e9a

py -3.12 -m venv .venv-kronos
.\.venv-kronos\Scripts\python.exe -m pip install -r requirements.txt
.\.venv-kronos\Scripts\python.exe -m pip install -r vendor/Kronos\requirements.txt

$env:PYTHONPATH='services/kronos_service'
$env:KRONOS_SOURCE_PATH='vendor/Kronos'
$env:KRONOS_MODEL_NAME='NeoQuasar/Kronos-small'
$env:KRONOS_TOKENIZER_NAME='NeoQuasar/Kronos-Tokenizer-base'
$env:KRONOS_DEVICE='cpu'
.\.venv-kronos\Scripts\python.exe -m trading_system_kronos_service
```

The main API reads `KRONOS_SERVICE_URL`, defaulting to
`http://127.0.0.1:8001`.

## Caveats

- The upstream Kronos repository is not a standard pip-installable package at
  the pinned revision, so this wrapper imports from `KRONOS_SOURCE_PATH`.
- Kronos pretraining is not validated for US and Canadian exchanges in this
  project yet. Forecasts are labeled as cross-market transfer forecasts.
- `predict_batch` requires identical lookback and `pred_len`; grouping is
  handled in `packages/quant/trading_system_quant/kronos/batching.py`.
